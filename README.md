## 📖 Sobre o projeto

O FirePredict AI é uma "sala de controle" para monitoramento de incêndios, feita para cruzar dados de satélite em tempo real com inteligência artificial e ajudar na identificação e previsão de focos de incêndio.

## ✨ Funcionalidades

- 📍 **Monitoramento geoespacial** — visualização de focos ativos usando dados da NASA FIRMS (últimas 24h, 48h ou 3 dias)
- 🍃 **Análise de biomassa (NDVI)** — mapeamento da saúde da vegetação via imagens de satélite Sentinel-2
- 🤖 **PYROS — Chat com IA** — assistente conversacional para consultar risco de incêndio em qualquer região do mundo
- 📸 **Validação de focos por foto** — envio de fotos de ocorrências locais, validadas por inteligência artificial (Gemma)
- 📅 **Previsão de risco — 7 dias** — projeção de risco de incêndio para a semana seguinte
- 🌡️ **Painel de dados ambientais** — temperatura, umidade, vento e índice FWI (Fire Weather Index) em tempo real

## 🛠️ Tecnologias

- Frontend web com integração de mapas e dashboards interativos
- Dados de satélite: NASA FIRMS e Sentinel-2
- Modelos de IA para análise de imagem e chat (Gemma)
- Deploy em produção via Vercel
